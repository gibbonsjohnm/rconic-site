How to use RCON on your Garry's Mod server from your phone

RCON lets you run server console commands remotely. With an RCON password set, you can manage your Garry's Mod server from your phone: run commands, change the map, and kick or ban players without opening the game.

1. Set an RCON password on the server

Open garrysmod/cfg/server.cfg on your server and add a line with a long, random password:

rcon_password "use-a-long-random-password-here"

Restart the server or change the map so it takes effect. On a rented server, edit server.cfg from your host's control panel (it's usually under Config Files or File Manager).

Treat the RCON password like an admin password: anyone who has it controls the server. RCON itself isn't encrypted, whichever tool you use, so make the password long and don't reuse it anywhere else.

2. Find the address and port

You need the server's IP address or hostname and its port. The default port is 27015; your host's control panel shows the real one. RCON uses the same port number as the game, but over TCP, while players connect over UDP.

  • Rented servers: RCON over TCP is normally open already.
  • Servers at home: forward the port for both TCP and UDP on your router, or RCON only works from your home Wi-Fi.

3. Add the server in Rconic

  1. Install Rconic from Google Play and open it.
  2. Tap + to add a server.
  3. Fill in Nickname (any name you like), Host / IP, Port, and RCON password.
  4. If your server runs the ULX admin mod, turn on Server runs ULX. This enables ULX broadcasts and admin grants.
  5. Tap Test connection, then Save.

Open the server from the list. When the password is accepted, you'll see RCON ✓ next to the server's status.

4. Run commands and manage the server

  • Console: type any command, such as status, and see the server's reply.
  • Change map: pick from the server's map list, with a filter for long lists.
  • Players: tap a player to kick, slay, ban for a set time or ban permanently. Every action asks for confirmation first.
  • Bans: see SteamID bans and lift them. Unbanning runs removeid and writeid, so it survives a restart.

Troubleshooting

"RCON password rejected" or "RCON authentication failed"

The password in Rconic doesn't match rcon_password on the server. Check for extra spaces or quotes, and make sure the server was restarted after you changed it. Edit the server in Rconic to update the saved password.

"You are banned from this server's RCON"

Source servers temporarily block an IP address after too many wrong passwords. Wait for the block to expire or restart the server, then fix the saved password before trying again. The sv_rcon_banpenalty and sv_rcon_maxfailures settings control how long and after how many attempts.

"Couldn't reach RCON"

The server didn't answer on TCP. It may be restarting; tap Retry. If it keeps happening, check that TCP is open on the server's port (see step 2).

Status works but RCON doesn't, only on mobile data

The server is probably at home and only the UDP port is forwarded. Forward TCP on the same port too.
